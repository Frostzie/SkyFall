# SkyFall Mod
[![Discord](https://img.shields.io/discord/1163847082080211025?label=discord&color=9089DA&logo=discord&style=for-the-badge)](https://discord.com/invite/qZ885qTvkx)
[![Made with Kotlin](https://img.shields.io/badge/Made%20With-Kotlin-orange?style=for-the-badge&logo=kotlin&logocolor=white)](https://kotlinlang.org/)<br>

Skyfall is a QOL mod for Hypixel skyblock. Mostly a personal project so features might be for very specific purposes.

### Features
- Highlight Active Pet.
- Cleaner autopet messages.
- Custom mob highlight. (Supports both hypixel name and vanilla)
- Disable death animation for mobs.
- Favorite Pets highlight.
- Disable hypixel server links button in pause menu.

Hopefully potato mode (from Odin 1.8.9) and favorite pets/contacts next.

<sub>All features are made to follow Hypixel rules (still use at your own risk like any mod). But if any admin believes a feature goes too far, happy to remove it.</sub>
